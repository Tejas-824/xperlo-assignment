# airoame

A React + Vite rebuild of the airoame design from Figma, styled with Tailwind CSS v4.

## Built with
- React 19 + Vite 8 (using the rolldown bundler, routes are code-split)
- Tailwind CSS v4 (`@tailwindcss/vite`, no config file needed)
- React Router v7
- react-helmet-async for page titles/meta tags

## Getting started

```bash
npm install
npm run dev       # runs at http://localhost:5173
npm run build     # builds for production into dist/
npm run preview   # lets you preview the production build locally
```
